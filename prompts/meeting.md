# 회의록 (doc_type=meeting)

회의 트랜스크립트를 정리해 결정·액션 중심으로 회의록을 작성하세요.

## 출력 구조

1. **회의 제목** — `title` 힌트 우선, 없으면 본문 첫 발언이나 주제에서 추정
2. **개요**
   - 일시 (트랜스크립트 메타·언급에서 추정; 정확치 않으면 "(추정)" 표기)
   - 참석자 (화자 분리 없으면 "발언자 다수" + 호칭/직책 등 본문 단서)
   - 주제 한 줄
3. **핵심 결정사항** — 불릿. 합의·결정된 사항만 (논의 중인 것 제외)
4. **액션 아이템** — 체크박스 형식 `- [ ] 담당자: 작업 (마감 추정)`
5. **논의 요약** — 섹션 헤딩으로 구분된 토픽별 요약. 각 섹션 2~5문장
6. **원문 인용** — `[HH:MM:SS] "발언 내용"` 5건 이내. 결정·전환점이 된 발언 위주

## Notion DB 속성 매핑 (database 타겟일 때, 스키마 확인 후 적용)

| 가능한 컬럼 | 채우는 값 |
|---|---|
| 회의 제목 / Title | 위 1의 제목 |
| 날짜 / Date | 잡 생성일 (오디오 녹음일 추정 못하면) |
| 참석자 | 위 개요의 참석자 텍스트 |
| 회의 유형 (multi_select) | 본문 톤에 따라 `정기회의`/`프로젝트 회의`/`RCA` 등 옵션 중에서 선택 (스키마에 정의된 것만) |
| 유관 부서 (multi_select) | 본문 키워드로 추정한 부서 (옵션 중에서만) |
| 주요 결정 & 액션 아이템 | 위 3+4 요약 |

## 금지

- 트랜스크립트에 없는 사실 추가 (할루시네이션) 금지. 모르면 "(불명)"으로 표시
- 욕설·민감정보는 트랜스크립트에서 발견돼도 그대로 옮기지 말고 `[...]` 로 마스킹
- 인용 발언은 한 줄 50자 정도, 길면 발췌
