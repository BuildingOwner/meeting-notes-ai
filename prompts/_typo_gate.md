# STT 오탈자 교정 게이트 (Notion 업로드 전 필수 실행)

회의록/문서 내용을 Notion에 올리기 **직전**, 생성한 텍스트 전체를 아래 체크리스트로 재검토하세요.
이 단계는 생략 불가입니다. 수정이 끝난 내용을 Notion에 올리세요.

---

## 검토 항목

### 1. 조사 오류
한국어 조사가 앞 단어와 맞지 않으면 수정합니다.
- `~를/을`, `~이/가`, `~은/는`, `~로/으로`, `~와/과` 혼용
- 예: `부담를` → `부담을` / `책이으로` → `책으로`

### 2. 받침·모음 오인식
발음은 비슷하지만 철자가 틀린 단어를 수정합니다.
- 예: `느낙` → `느낌` / `늘어졌는데` → `늘었는데` / `과잌` → `과잉` / `쳋학` → `철학`

### 3. 영어 음독 오인식
영어 단어를 한국어 발음으로 잘못 적은 경우를 수정합니다.
- 예: `컨밤션` → `컨벤션(convention)` / `딥리버리` → `딜리버리(delivery)` / `필턴링` → `필터링(filtering)`

### 4. 의미 불통 파편 단어
문장 안에 뜬금없이 나타나는 1~3음절 파편 단어를 처리합니다.
- 앞뒤 문맥으로 복원 가능하면 교체
- 복원 불가능하면 `[불명]` 표시

### 5. 문맥 불일치 단어
전후 문맥과 의미가 맞지 않는 단어는 발음 유사 단어로 교체합니다.
확신하기 어려우면 `(추정: [원문])` 형식으로 병기합니다.

---

## 교정 원칙

- **의미 변경 금지** — 오탈자·오인식 수정만 허용, 내용 재해석 금지
- **고유 표현 보존** — 강사·발표자의 신조어, 의도적 줄임말은 수정하지 않음
- **확실한 것만 바로 교정** — 불확실하면 `(추정)` 병기
- **수정 로그 불필요** — 교정 결과를 바로 반영하면 됨, 별도 목록 작성 불필요
