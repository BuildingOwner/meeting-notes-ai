# STT 오탈자 교정 게이트 (Notion 업로드 전 필수 실행)

회의록/문서 내용을 Notion에 올리기 **직전**, 생성한 텍스트 전체를 아래 체크리스트로 재검토하세요.
이 단계는 생략 불가입니다. 수정이 끝난 내용을 Notion에 올리세요.

---

## 검토 항목

### 1. 조사 오류
한국어 조사가 앞 단어와 맞지 않으면 수정합니다.
- `~를/을`, `~이/가`, `~은/는`, `~로/으로`, `~와/과` 혼용
- 예: `부담를` → `부담을` / `책이으로` → `책으로`

### 2. 받침·모음 오인식
발음은 비슷하지만 철자가 틀린 단어를 수정합니다.
- 예: `느낙` → `느낌` / `늘어졌는데` → `늘었는데` / `과잌` → `과잉` / `쳋학` → `철학`

### 3. 영어 음독 오인식
영어 단어를 한국어 발음으로 잘못 적은 경우를 수정합니다.
- 예: `컨밤션` → `컨벤션(convention)` / `딥리버리` → `딜리버리(delivery)` / `필턴링` → `필터링(filtering)`

### 4. 의미 불통 파편 단어
문장 안에 뜬금없이 나타나는 1~3음절 파편 단어를 처리합니다.
- 앞뒤 문맥으로 복원 가능하면 교체
- 복원 불가능하면 `[불명]` 표시

### 5. 문맥 불일치 단어
전후 문맥과 의미가 맞지 않는 단어는 발음 유사 단어로 교체합니다.
확신하기 어려우면 `(추정: [원문])` 형식으로 병기합니다.

### 6. 사내 고유명사·제품·도구 사전

문맥상 해당되면 아래 표 기준으로 일괄 치환 (대소문자·띄어쓰기 유의).

| 폴라스타 / 폴 스타 / 폴리스타 / 폴스타 / 콜스타 | Polestar / ForeStar | 제품·서비스명 (문맥 확인) |

| 자주 나오는 오인식 | 정답 | 비고 |

| QN / 큰 / 쿤 | Qwen | LLM 모델명 |

### 8. 영문 약어·코드 식별자

Whisper가 한글로 음차한 부분은 원어 복원:
- "에이피아이" → API, "유알엘" → URL, "디비" → DB, "엠씨피" → MCP, "엘엘엠" → LLM
- 단, 발화자가 일부러 풀어 읽었으면 원문 보존 + `(API)` 식 괄호 보조

### 9. 자주 틀리는 관용구

| 오인식 | 정답 |
|---|---|
| 빙산의 일감 | 빙산의 일각 |
| 어쩔 수 업이 | 어쩔 수 없이 |
| ~한거 같애요 | ~한 것 같아요 |
| 갔다왔어요 / 갔다 왔어요 | 갔다 왔어요 |

### 10. 민감정보 재확인

- 욕설·비속어 → `[...]` 마스킹 (인용에서도 마스킹)
- 개인정보(주민번호·전화번호·계좌·이메일 등) → `[마스킹]` 처리
- 사내 비공개 식별자(고객사명·내부 코드명)는 트랜스크립트에 명시되어 있어도 본문에 그대로 옮겨도 되는지 한 번 더 확인. 의심되면 `[?: 코드명]` 마킹

## 교정 원칙

- **의미 변경 금지** — 오탈자·오인식 수정만 허용, 내용 재해석 금지
- **고유 표현 보존** — 강사·발표자의 신조어, 의도적 줄임말은 수정하지 않음
- **확실한 것만 바로 교정** — 불확실하면 `(추정)` 병기
- **수정 로그 불필요** — 교정 결과를 바로 반영하면 됨, 별도 목록 작성 불필요
- **인용은 원문 보존** — `[HH:MM:SS] "..."` 인용 블록은 원문 유지, 줄 끝에 `(추정: 정정후보)` 만 추가
