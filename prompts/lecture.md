# 강의 노트 (doc_type=lecture)

강의 트랜스크립트를 정리해 학습자가 복습 가능한 노트로 작성하세요.

## 출력 구조

1. **강의 제목** — `title` 힌트 우선, 없으면 본문 도입에서 추정
2. **개요**
   - 일시 (추정)
   - 강사 (단서·메타에서 추정)
   - 회차 (예: "N번째 세션" 언급 있으면 표시)
   - 주제 한 줄
3. **학습 목표** — 강사가 명시한 목표 또는 본문에서 추론한 학습 결과 3~5개 불릿
4. **개념 정리** — 표 형식 권장. 컬럼: `개념 | 정의 | 비고`. 신규 개념·중요 용어 위주
5. **본문 정리** — 강의 흐름대로 섹션 헤딩으로 구분. 각 섹션 2~5문장 + 필요시 코드/예시 블록
6. **Q&A 정리** — 강의 중 학습자 질문·답변이 있으면 정리. 없으면 생략
7. **실습 / 과제** — 강사가 부여한 과제 or "이 다음 주까지 ..." 류 액션. 체크박스로
8. **원문 인용** — `[HH:MM:SS] "발언 내용"` 10건까지. 핵심 정의·통찰 위주 (강의는 인용 비중 약간 높음)

## Notion DB 속성 매핑 (database 타겟일 때)

| 가능한 컬럼 | 채우는 값 |
|---|---|
| 회의 제목 / Title | 위 1의 제목 |
| 날짜 / Date | 잡 생성일 |
| 회의 유형 (multi_select) | `교육` 또는 본문 톤에 맞는 옵션 (스키마 정의 내) |
| 참석자 | "강사: 김OO, 수강생 다수" 류 |
| 유관 부서 | `교육` 옵션 (스키마에 있으면) |
| 주요 결정 & 액션 아이템 | 위 7의 실습/과제 요약 |

## 금지

- 강사가 명시한 정의를 멋대로 다른 정의로 바꾸지 말 것
- 학습자가 헷갈리지 않게, 추정·추가 설명은 본문 안에서 "추가 참고:" 같은 명시적 라벨로 분리
