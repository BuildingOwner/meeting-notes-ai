# 강의 노트 (doc_type=lecture)

강의 트랜스크립트를 정리해 **학습자가 복습·적용 가능한** 구조화된 노트를 작성하세요.
강사의 설명 흐름을 따르되, 나중에 혼자 읽어도 이해되는 수준으로 압축합니다.

## 출력 구조

### 1. 강의 제목
`title` 힌트 우선, 없으면 본문 도입에서 추정.

### 2. 개요

| 항목 | 내용 |
|---|---|
| 일시 | 트랜스크립트 메타·언급에서 추정; 불확실하면 "(추정)" 표기 |
| 강사 | 단서·메타에서 추정 (불명이면 "(불명)") |
| 회차 | "N번째 세션" 언급 있으면 표시 (불명이면 생략) |
| 주제 | 한 줄 요약 |
| 선수 지식 | 강사가 언급한 "미리 알아야 할 것" 또는 본문에서 전제하는 개념 (없으면 생략) |

### 3. 학습 목표
강사가 명시한 목표 또는 본문에서 추론한 학습 결과 **3~5개 불릿**.
"이 강의를 마치면 ___를 할 수 있다" 형태로 작성.

### 4. 핵심 포인트 요약
강의에서 반드시 기억해야 할 개념·원리 **5~7개 불릿**.
- 각 불릿은 1문장, 시험·실무에서 바로 활용 가능한 형태
- 개념 정의가 아닌 "이것이 왜 중요한가"를 담을 것

### 5. 개념 정리

| 개념 | 정의 | 예시 / 비고 |
|---|---|---|
| 개념명 | 강사가 제시한 정의 (임의 수정 금지) | 강의 중 언급된 예시나 맥락 |

신규 개념·중요 용어 위주. 없으면 섹션 생략.

### 6. 강의 내용 정리
강의 흐름대로 **섹션 헤딩(굵게)** 으로 구분. 각 섹션 2~5문장.
필요시 코드·수식·예시 블록 포함.

### 7. Q&A 정리
강의 중 학습자 질문·강사 답변이 있으면 정리. 없으면 섹션 생략.

**Q:** (질문자 불명이면 "학습자") 질문 내용
**A:** 강사 답변 요약

### 8. 실습 & 과제
강사가 부여한 과제 또는 "다음 시간까지 ..." 류 액션. 없으면 섹션 생략.

| 항목 | 내용 | 마감 |
|---|---|---|
| [ ] | 과제/실습 내용 | YYYY-MM-DD 또는 "(미정)" |

### 9. 다음 강의 예고
강사가 언급한 다음 시간 주제·내용. 없으면 섹션 생략.

### 10. 원문 인용
`[HH:MM:SS] "발언 내용"` — **10건까지**. 핵심 정의·통찰 위주 (강의는 인용 비중 약간 높음).

## Notion DB 속성 매핑 (database 타겟일 때, 스키마 확인 후 적용)

| 가능한 컬럼 | 채우는 값 |
|---|---|
| 회의 제목 / Title | 위 1의 제목 |
| 날짜 / Date | 잡 생성일 |
| 회의 유형 (multi_select) | `교육` 또는 본문 톤에 맞는 옵션 (스키마 정의 내) |
| 참석자 | "강사: 김OO, 수강생 다수" 류 |
| 유관 부서 | `교육` 옵션 (스키마에 있으면) |
| 주요 결정 & 액션 아이템 | 위 8의 실습/과제 요약 |

## 금지

- 강사가 명시한 정의를 다른 정의로 바꾸지 말 것
- 추정·추가 설명은 본문 안에서 "추가 참고:" 같은 명시적 라벨로 분리
- 핵심 포인트를 단순 목차 나열로 채우지 말 것 — 각 항목이 독립적으로 의미를 가져야 함
