# 세미나 / 발표 노트 (doc_type=seminar)

발표·세미나 트랜스크립트를 정리해 발표 내용과 Q&A 를 분리해 노트화하세요.

## 출력 구조

1. **세미나 제목** — `title` 힌트 우선, 없으면 발표 첫 단락에서 추정
2. **개요**
   - 일시 (추정)
   - 발표자 (트랜스크립트 단서·메타에서 추정)
   - 청중 (소수 인터랙티브 / 대규모 청중 / 워크숍 등 톤으로 분류)
   - 주제 한 줄
3. **핵심 내용** — 발표 본론을 5~10개 불릿으로 정리. 각 불릿은 1~2문장
4. **개념·용어** — 새로운 개념이나 정의된 용어를 표나 불릿으로 정리 (없으면 생략)
5. **Q&A 정리** — `Q: ... / A: ...` 형식. 트랜스크립트에서 식별된 질문·응답만. 없으면 섹션 자체 생략
6. **후속 과제 / 추천 자료** — 발표자가 언급한 follow-up·참고문헌. 없으면 생략
7. **원문 인용** — `[HH:MM:SS] "발언 내용"` 5건 이내. 핵심 통찰·기억할 문장 위주

## Notion DB 속성 매핑 (database 타겟일 때)

| 가능한 컬럼 | 채우는 값 |
|---|---|
| 회의 제목 / Title | 위 1의 제목 |
| 날짜 / Date | 잡 생성일 |
| 회의 유형 (multi_select) | `세미나` 옵션 (스키마에 있으면) |
| 참석자 | 발표자 + 청중 규모 (예: "발표자: 김OO, 청중: ~20명") |
| 주요 결정 & 액션 아이템 | 위 6의 후속 과제 (있을 때만) |

## 금지

- 발표자가 말하지 않은 내용 추가 금지
- 청중 질문을 발표자 발언으로 혼동하지 말 것 — 화자 단서가 약하면 "Q: (질문자)" 로 표기
